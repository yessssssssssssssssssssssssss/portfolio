# Arthur Baets — Developer Portfolio

A modern responsive portfolio website built with HTML, CSS, and JavaScript.

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open the repository's **Settings**.
4. Go to **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save.

GitHub will provide a public URL for the site.

## Customize

Search the files for:
- `https://github.com/` and replace it with your GitHub profile URL.
- `your@email.com` and replace it with your email.
- `href="#"` in project cards and replace each one with its repository URL.
- Project names/descriptions with your real GitHub projects.

## Files

- `index.html` — website structure
- `style.css` — styling and mobile layout
- `script.js` — small interactive features
